# 지도: 발표·질의응답을 사람처럼 자연스럽게 (AI 느낌 줄이기)

Label: wayfinder:map

## Destination

바로 구현에 들어갈 수 있는 **구현용 기획서**: 목소리·대본 말투·질문 후 침묵·화면과 말의 타이밍·구간 길이에 대해 "무엇을 어떻게 바꿀지"가 모두 정해진 상태.
이 기획서대로 오늘(2026-10-29) 오후 5시 제출 전까지 전부 구현하고, 아래 점검 항목으로 리허설해 통과하는 것이 끝이다.

## Notes

- 대상 앱: 이 폴더의 Ling AI Presenter (README.md, `.scratch/ai-presenter/destination-and-requirements.md`).
- 결정 방식: 티켓은 Ling이 직접 고르는 결정만 둔다(그 밖의 구현 세부는 구현 때 결정). 한 세션에 티켓 하나.
- 참고 초안: `.scratch/ai-presenter/naturalness-plan.md` (다른 세션이 쓴 초안. 결정이 아니라 아이디어 목록으로만 쓴다).
- 제약
  - 무료 Gemini TTS: 모델당 하루 10회. 주력 `gemini-3.8-flash-tts`는 오늘 한도 소진, 한국 시간 오후 4시경 초기화.
  - 마감: 오늘 오후 5시 제출. 구현·리허설 시간을 남기려면 결정은 오전 중에 끝낸다.
  - Windows·Mac 모두 동작.
- 구현 때 함께 할 일(결정 불필요): GitHub Actions로 Mac 빌드(zip) 만들기 — 확인은 Mac 사용자가 해야 함.
- 판단 기준: 아래 점검표로 Ling이 직접 리허설 1회.
  - 첫 10초 안에 "읽고 있다"는 느낌이 없다
  - 질문을 보낸 뒤 1초 안에 무언가 반응(소리)이 나온다
  - 강조·페이지 이동이 말보다 늦지 않고, 1초 넘는 무음이 없다
  - 발표와 답변의 목소리 톤이 같다
  - 발표 당일 소개 전체에 음성 API 호출이 0회
- 매 세션 참고 스킬: grilling, domain-modeling

## Decisions so far

- [대본을 어떤 말투와 길이로 쓸지](issues/03-script-style.md): 해요체·습니다체를 내용에 따라 섞고(같은 어미 3연속 금지), 문장은 40~80자로 길고 짧게 섞음·AI 고지 없음. 최소 10분(약 4,300자, 12구간). 대표작(진회영·가면·모탈리티 클로즈)에 실제 비하인드를 넣고, 지금 대본을 손으로 고친다
- [질문 후 침묵을 어떻게 채울지](issues/04-qa-silence.md): 질문 즉시 미리 녹음한 맞장구 재생(늦으면 두 번째 맞장구 1회), 예상 질문 5~8개는 답변 음성까지 미리 만들고, 실시간 답변은 1~3문장
- [화면과 말을 어떻게 맞출지](issues/05-screen-timing.md): 핵심 문장만 0.3초 먼저 강조(대상은 대본에 ★로 미리 저장·수정 가능), 아바타 동시 이동, 구간 끝 다리 문장 중에 페이지 이동해 무음 제거, 미리 만든 답변은 맞장구 중 페이지 이동
- [예상 질문과 답변 내용 정하기](issues/06-expected-questions.md): 예상 질문 7개(앱 제작·저자성·진회영·가면·모탈리티 클로즈·5주차 구조화·앞으로의 작업)의 답변·페이지·★ 확정, 맞장구 4개·두 번째 맞장구 2개, 한국어 질문에만 미리 만든 답변 사용

- [ElevenLabs 가입하고 API 키 받기](issues/01-elevenlabs-api-key.md): 키 발급·권한(Voices Read) 추가. 무료 플랜은 기본 목소리만 API로 사용 가능
- [어떤 목소리로 발표하고 답할지](issues/02-voice-choice.md): ElevenLabs 기본 목소리 Bella로 발표·맞장구·답변 전부. 미리 만드는 음성 25개는 오늘 생성해 preset에 포함
